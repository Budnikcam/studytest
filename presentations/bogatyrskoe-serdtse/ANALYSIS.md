# Анализ презентации «Набор в сборную · Богатырское сердце»

Исходник: PDF, 12 вертикальных слайдов (формат сторис), ФФС Смоленской области.

## Вердикт

Сильная визуальная база и правильный тон для аудитории ветеранов СВО. Для набора материал слабый из‑за устаревших дат, раздутого объёма и отсутствия прямого контакта на финале.

## Что работает

- Прямой тон без жалости: «протез — не помеха», «опыт в CS2 не нужен».
- Понятная формула дисциплины: CS2 + лазертаг = общий результат.
- Живые фото лазертага, фирменные зелёный/жёлтый на чёрном.
- FAQ закрывает типовые возражения.
- Реферальный призыв «перешлите ветерану» — уместный канал роста.

## Ошибки и недочёты

### Критично

1. **Устаревшие даты** — «1 марта 2026» и «сентябрь 2026» на слайде про турнир. Для аудитории это сигнал, что материал неактуален.
2. **Слабый CTA** — «ответьте тому, кто прислал». Нет телефона, Telegram, QR, формы. При пересылке запись обрывается.

### Высокий приоритет

3. **12 слайдов** для мессенджера — слишком длинно; смысл тонет в повторах.
4. **Дубли** — «бесплатно», «протез ок», «CS2 с нуля» повторяются на 02/03/07/11.
5. **Нет конкретной даты старта** — только «согласуем с группой»; нечего поставить в календарь.

### Средний

6. Слово «фиджитал» объясняется только на 4-м слайде.
7. Фото спортсмена с протезом появляется на 10-м — поздно для сигнала «это про нас».
8. На слайде турнира мелькает VR-тактика, в секции её нет — путаница по дисциплинам.
9. «ПК и снаряжение выдаём» спрятано в футере, хотя это сильный аргумент.

### Низкий

10. Справка от врача без инструкции, где её получить в Смоленске.
11. Нет лица тренера, локальных цифр набора, логотипов партнёров.
12. Глитч-дубль слова «СБОРНУЮ» на титуле визуально похож на баг.

## Идеальная структура (8 слайдов)

| № | Задача | Содержание |
|---|--------|------------|
| 01 | Крюк | Для кого + бесплатно + место + контакт в футере |
| 02 | Продукт | CS2 + лазертаг, «всё выдаём» |
| 03 | Возражения | Протез / опыт / справка — один раз |
| 04 | Тренировка | 10′/35′/35′/10′ + адрес |
| 05 | Цель | «Богатырское сердце» с **актуальными** датами |
| 06 | Путь | Запись → группа → сборная → старты |
| 07 | FAQ | Пять коротких ответов |
| 08 | CTA | Telegram + телефон + шаблон сообщения + реферал |
